Workflow:
1. A bug is assigned to you in Asana.
2. Agent reads the issue and acceptance criteria.
3. Agent explores the repository.
4. Agent identifies the probable root cause.
5. Agent reproduces the bug using tests or a controlled environment.
6. Agent proposes a solution.
7. Agent creates a branch and implements the fix.
8. Agent runs tests and verifies the changes.
9. Agent opens a pull request for human review.
